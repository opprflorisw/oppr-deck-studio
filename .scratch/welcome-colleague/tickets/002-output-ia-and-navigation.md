## Question

Where does this output type live in the app, and how does the Output/Create
structure change to hold it?

The user asked for "subpages" - today Output splits Decks / Social, and Create has
the Social studio cards (carousel, post, image, article, thumbnail). A "Welcome a
colleague" output is seeded from an upload, not composed from the library, so it
does not fit the existing Social studio card flow cleanly.

Decide:

- Is this a new **kind** alongside carousel/post/image (folder
  `social/linkedin/<date>_welcome-<name>/`), or a new top-level area?
- What the **subpage** is: a distinct Create entry ("Welcome a colleague") with an
  upload-first flow rather than a compose-from-library flow.
- How it shows in **Output**: its own tab/subpage, or mixed into Social output with
  a kind badge.
- Whether the IA leaves room for a future "team" family (anniversaries, farewells)
  without designing them now.
