# Best practice — LinkedIn post text

## Platform practices

Source: `.scratch/deck-app/research/05-linkedin-formats.md` (2026-07-22).

- **3.000-character** limit. The **"see more" fold** falls at ~210 chars on
  desktop, **~140 on mobile** — the hook must land in the first 140.
- Optimal length 1.300–2.500 chars. Blank lines collapse (especially in the
  mobile editor): use a single Enter between paragraphs.
- **0–3 hashtags** (hashtag-follow was removed in 2024; no standalone reach
  boost). Tag only people actually involved.
- **Unicode bold** (Mathematical Alphanumeric letters) renders across clients,
  but screen readers spell it letter-by-letter and LinkedIn search can't index
  it.
- Posting from a **personal profile** reaches ~5–10× a Company Page.

## How Oppr applies it

- Structure: **hook (<140 chars)** → 2–3 short paragraphs → CTA → hashtags.
  Write the hook first and test it truncated at 140.
- **Unicode bold: 1–3 short phrases max**, never numbers, never a searchable
  keyword, never a whole sentence. Prefer line breaks and plain emphasis.
- Link goes in the **first comment**, not the body. 3 hashtags, manufacturing /
  operations flavored.
- Post from Floris's profile; mirror on the Oppr Page if useful.
- Same brand voice as everything else: concrete, no hype, European numbers, no
  em dashes, payback illustrative.
