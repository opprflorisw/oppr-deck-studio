# library/ — the element library

Reusable slides and described images. Edited only in **Edit mode**
(`/edit-canonical`), never from `/new-deck`.

## What a slide is

`library/slides/<id>/`:
- `slide.html` — exactly ONE `<section>…</section>`, self-contained markup, no
  `<html>`/`<head>`. It is copy-paste identical to what sits in a deck, except
  deck-level bits are placeholders: `{{deck_footer}}`, `{{total}}`,
  `{{cover_meta}}` (cover only), and image/asset paths are `{{asset}}brand/img/…`.
- `meta.yaml` — `id`, `role` (the skeleton slot it fills), `title`, `css`,
  `entitlement`, `language`, `tags`, `images` (repo-relative), `variables`
  (auto: which `{{…}}` it uses), `used_in` (which deck types), `notes`.
- `thumb.png` — generated by `tools/build-slide-catalog.ps1`; do not hand-edit.

## The CSS-graduation rule (load-bearing)

A library slide may NOT carry one-off inline styles that only make sense in one
deck. If a slide needs a style, that style **graduates into the shared
stylesheets first** (`templates/showcase.css`, or `deck.css` if truly systemic)
and gets a specimen in `library/design-system/`. This is what keeps slides
portable and the design system honest.

## Roles

`cover · idea · why-now · problem-recognition · when-time-matters · platform ·
product-flow · outcomes · evidence · kpi · engagement · step-detail · acceptance ·
running-projects · who-is-oppr · cta · closer`. A role may have several slides;
recipes reference slides by role, the intake proposes the best fit.

## Images

`brand/img/library.json` describes every image (description + tags +
suggested_use + entitlement). At build time Claude reads it and picks images BY
MEANING, honoring `entitlement`. Reuse the chosen image's `description` as its
`alt`. Regenerate the contact sheet + drift check with
`tools/build-asset-index.ps1`.

## icons/

`library/icons/` is the **reusable line-icon set** (24×24, stroke-only,
`currentColor`). Never paste a one-off `<svg>` into a new slide: use the
**`{{icon:NAME}}`** token (assembly inlines it) and colour it with a brand role
via the `.di` helper. Add a new icon there first if one is missing. Full rules
in `library/icons/CLAUDE.md`.

## design-system/

Block specimens (one small HTML page per token/block/pattern, rendered from the
real stylesheets). They are the source synced to the "Oppr Deck System" project on
claude.ai/design. A new slide composes only from documented blocks (see SPEC §10b).
